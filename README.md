### What I've built

**🏭 Agentic AI for industrial assets — ABB (Master's thesis)**
An orchestrator-based agent framework that pulls from several data sources and returns one grounded, aggregated answer, built on an LLM-enhanced Asset Administration Shell environment with a Neo4j knowledge graph as its knowledge base.

**♻️ Digital product passport UI — ABB**
Designed and developed the interface for an AAS-based product passport supporting sustainable machine development. It is in use by ABB's automation team.

**🗣️ Talk to the machine — PTW, TU Darmstadt**
An LLM for an industrial machine's HMI: operators describe what they want in plain language, the model generates the G-code and answers questions about the machine.

**🤖 Norra, the receptionist robot**
A bilingual (German/English) receptionist app for the OrionStar GreetingBot Nova: visitor check-in, appointment booking, package delivery, badge printing and robot-guided wayfinding. FastAPI backend wired into Microsoft 365 calendars and email.

**🎬 Disjoint Temporal Branching — video understanding research**
Faster Video Moment Retrieval on long-form video by combining Video Parallel Scaling, training-free prompting (Chrono) and speculative decoding, with LLM debate explored as a way to merge parallel branches.

**🎤 TEDxTUDarmstadt website**
Led the redesign and development as IT & Operations Team Lead. The site brought in 250 registrations for the November 2025 event.

**❤️ Federated learning research — Qatar University**
Privacy-preserving arrhythmia detection on IoT devices, plus federated learning and a comparative ML study for small-signal stability in power systems.
